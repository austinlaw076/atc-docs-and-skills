# ATC v1.1 restricted local Runtime

Purpose: enforce the approved no-tools/no-filesystem/no-network research boundary for a narrowly supported local Python worker. Audience: trusted Host operators. Sources and accepted dependencies enter as bounded JSON on stdin; results leave as bounded JSON on stdout. No model provider, keys, paid service or external deployment is added.

Acceptance:
1. A fresh Linux x86-64 Python process installs a native libseccomp default-deny syscall filter before executing any worker code. Deny filesystem opens/mutations, network sockets, exec/fork/clone, ptrace/process control and policy changes. Only bounded stdio, memory, time, signal handling and process exit operations are available. Clear inherited environment and close unrelated descriptors. Set memory/CPU/core/file limits before worker execution.
2. If platform, library, limits, filter installation or readiness verification fails, do not execute worker code; terminate the child and fail the request. Gate worker execution on a bounded host acknowledgment bound to the verified readiness frame; missing/invalid acknowledgment prevents execution. Never silently fall back to advisory CallbackHostRuntime.
3. Add optional PRD runtime_policy=seccomp_python_stdio_v1. Strict Coordinator requests require a matching trusted-host isolation attestation before receive, and recheck it on accepted reports/dependency dispatch. Bind profile, actual child identity, prompt hash, worker/bootstrap/policy hashes and limits. A trusted host can still forge its own state; attestations are not remote signatures.
4. HostDispatcher validates the required runtime profile, records readiness evidence and terminates active children on cancellation, timeout, invalid JSON, output limits or other failure. Host output buffering is bounded; no worker-selected shell or command is executed.
5. Run real child-process negative probes for file read/write, native open variants, traversal/symlink, TCP/UDP/Unix socket creation, exec/fork/thread creation, parent memory/process access and filter changes. Verify canaries unchanged, clean environment/descriptors, ordinary in-memory research JSON still works, and resources/time/output limits fail safely. Unsupported capability must be reported as blocked, not passed.
6. Preserve previous code/tests and historical runs. Use a new v1.1 compiled contract/run. Existing PRDs without runtime_policy retain explicitly advisory behavior; they never inherit an enforced label. Distinguish real local restricted-process tests and fixture research from live model-agent validation, which is not established by these tests.

Boundary: this is a restrictive local process profile, not general container/VM isolation, a kernel exploit defense, or a complete information-flow sandbox. Worker startup dependencies must be preloaded by the trusted bootstrap. Runtime networking, file access after startup and new processes are intentionally unavailable. Native model-provider integration inside this profile remains a separate gate.
